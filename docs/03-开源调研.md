# 开源调研：多模态 UI 解析 / 视觉回归 / LLM 评测

> 调研日期 2026-10-13；star 数为当日实测。选型结论：**输入侧借 UI 解析与评测框架的"证据与置信"思想；输出侧借视觉回归工具的 diff 语义 + 评测框架的断言模式**，全部以零依赖方式内聚实现。

## 1. OmniParser（microsoft/OmniParser）⭐ 25.5k

https://github.com/microsoft/OmniParser

- **核心思想**：截图 → 结构化 UI 元素（位置/类型/文本），为 Agent 提供可操作的页面解析；对低保真/非标准 UI 的判定置信度显著下降。
- **借用点**：VLM 输出协议（components + confidence + present）即其"SOD+功能语义解析"的简化镜像；**分层置信路由**（清晰截图直接用 / 手绘稿强制人工确认）对应其在退化输入上的行为边界。
- **不采用原因**：需要真实模型推理（本仓库验证闭环工程，不验证模型能力）；生产接入时它是输入侧候选组件之一。

## 2. Playwright（microsoft/playwright）⭐ 97.6k

https://github.com/microsoft/playwright

- **核心思想**：浏览器自动化；`toHaveScreenshot()` 断言内置像素比对与区域遮罩。
- **借用点**：**预览截图管线的形态**（给定配置 → headless 渲染 → 截图）；"同一输入必须渲染出同一像素"的确定性要求——`render.py` 由此定为纯函数渲染器。
- **不采用原因**：低代码平台预览路由尚无 headless 服务（源文档 3.2：截图管线是最大隐性工程量）；本仓库以 PPM 文本位图实现其最小形态，生产化时替换为 headless Chrome 截图。

## 3. pixelmatch（mapbox/pixelmatch）⭐ 7.0k

https://github.com/mapbox/pixelmatch

- **核心思想**：极简像素 diff（逐像素色差 + 阈值 + 变化区域标记），几乎所有视觉回归工具的底层。
- **借用点**：`pixel_diff.py` 的算法骨架（per-pixel distance → threshold → changed ratio + bbox）；"diff 回答变在哪，不回答好不好"的语义边界。
- **不采用原因**：JS 库；其 Python 移植（PixelMatch 类）与 60 行自实现之间的权衡——自实现零依赖且可测试。

## 4. BackstopJS（garris/BackstopJS）⭐ 7.2k

https://github.com/garris/BackstopJS

- **核心思想**：视觉回归测试：场景 → 截图 → 与基准比对 → 报告（requirement/trigger/ready 事件模型）。
- **借用点**：**"声明式场景 + 基准比对"的回归组织方式**；reports 的可视化思想（bbox 高亮变化区域）。
- **不采用原因**：绑定浏览器渲染与 Node 工具链。

## 5. jest-image-snapshot（americanexpress/jest-image-snapshot）⭐ 3.9k

https://github.com/americanexpress/jest-image-snapshot

- **核心思想**：把"截图比对"变成一条单元测试断言（toMatchSnapshot）。
- **借用点**：**属性断言与像素断言同为一等测试公民**的组织方式——`test_output.py` 中断言/diff/提案全为确定性单测。
- **不采用原因**：JS/Node 生态。

## 6. DeepEval（confident-ai/deepeval）⭐ 18.8k

https://github.com/confident-ai/deepeval

- **核心思想**：LLM 输出的结构化评测（含 hallucination 指标：输出中"无上下文支撑"的断言占比）。
- **借用点**：**幻觉的操作性定义**——"无证据支撑的输出项"= 本仓库的 `present=False` / 无 source 节点；`dark_hallucination_count` 即其 hallucination metric 的确定性版本。
- **不采用原因**：指标依赖真实模型与嵌入；本仓库以结构化 evidence 字段构造同构判定。

## 7. promptfoo（promptfoo/promptfoo）⭐ 25.9k

https://github.com/promptfoo/promptfoo

- **核心思想**：prompt/模型的回归评测（断言库 + 期望输出对比 + CI 集成）。
- **借用点**：意图树 golden 断言的"逐场景期望"组织（问题③仓库 golden set 同源思想）；CI 强制回归。
- **不采用原因**：面向真实模型调用的评测；结构已内化为 tests/。

## 结论矩阵

| 需求 | 采用方案 | 思想源头 |
|---|---|---|
| 截图→结构（含置信） | VLM 输出协议 + 分层路由 | OmniParser |
| 反幻觉 | evidence 字段 + assumptions + 暗幻觉计数 | DeepEval hallucination metric |
| 预览截图管线 | 确定性渲染器（PPM） | Playwright headless 截图 |
| 变化定位 | 逐像素 diff + bbox | pixelmatch |
| 修改确实发生 | 属性断言逐条机检 | jest-image-snapshot 断言式 |
| 模糊指令降维 | 3 候选/6 色卡 + 点选 | 源文档 3.2 提案式交互 |
