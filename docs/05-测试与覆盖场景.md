## 边界场景说明

- **歧义即显式**：同轮双实体的"那个"、无先行的"那个"、手绘稿、低置信组件——全部走"进 assumptions 问人"而非静默拍板；这本身就是设计目标（闭合不了的指代是 NLP 老硬骨头，LLM 只是把失败变得更自信）。
- **幻觉的判定不依赖置信度**：`present=False` 的项置信度 0.95 照样进假设清单——"自信的私货"恰是最危险的一类。
- **VLM 协议**：`vlm.py` 的输出（components + present + confidence + requires_human_review）与 OmniParser 类解析器的结构对齐；确定性回归以测试语料（tests/vlm_scenarios.py）经测试替身注入，live 测试对真实 VLM 在线运行（env-gated）。测试替身仅存在于 tests/，产品代码不含脚本化模型。
